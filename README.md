# boostrepo

Boost HTML/Markdown repo fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/boostrepo/

## Install / run

```bash
git clone https://github.com/theworker02/boostrepo.git
cd boostrepo
node src/cli.js
node --test
```
